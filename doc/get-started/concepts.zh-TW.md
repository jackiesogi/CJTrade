# 基本概念

這些頁面會用到一些交易和 CJTrade 的用語。每個詞都在這裡用白話解釋一次，後面的內容就可以直接使用。你可以先大致瀏覽，遇到看不懂的詞再回來查。

## 交易用語

**股票代號（Symbol）**
:   股票在交易所的代碼。`2330` 是台積電，`0050` 是元大台灣 50 ETF。CJTrade 一律只用代碼本身，不會寫成 `2330.TW`。

**券商（Broker）**
:   保管你的現金和股票，並把你的委託送到交易所的公司。在 CJTrade 裡，只要能接收委託的都算券商：模擬券商 **ArenaX**，或正式券商 **Sinopac**。

**委託（Order）**
:   一筆買進或賣出的指示：哪一檔股票、多少股、什麼價格。下了委託不代表已經買到或賣掉，它只是一個請求。

**成交（Fill）**
:   真的完成的委託。買進委託要有人願意用你的價格賣給你，才會*成交*。只有成交的委託會改變你的現金和持股。

**限價（Limit price）**
:   你能接受的最差價格。買進限價 1000 的意思是「用 1000 或更便宜的價格買」。如果市價一直沒有跌到 1000，委託就會一直等著。

**整張與零股（Lot / odd lot）**
:   在證交所，一*張*是 1,000 股。*零股*委託則是以一股為單位交易。CJTrade 的簡便函式預設交易零股，所以 `quantity=1` 就是一股，範例跑起來比較便宜。

**ROD、IOC、FOK**
:   委託保留多久。**ROD**（Rest of Day，當日有效）會一直等到當天收盤，也是預設值。IOC 和 FOK 則是立刻成交，否則就取消。

**庫存（Position）**
:   你持有某一檔股票的股數，以及買進的平均價格。

**餘額（Balance）**
:   帳戶裡的現金，單位是新台幣。

**交易時段（Trading session）**
:   證交所的交易時間是週一到週五 09:00 到 13:30，國定假日除外。

**手續費與證交稅（Commission and tax）**
:   每次成交都要付成交金額 0.1425% 的手續費（最低 NT$20）。賣出還要付證交稅：股票 0.3%，ETF 0.1%（代號開頭是 `0` 的）。CJTrade 在每一筆模擬成交上也會收這些費用。

## 價格用語

**K 棒（Bar / K-bar）**
:   一段時間內價格的摘要：第一筆價格（*開盤價*）、最高價（*最高*）、最低價（*最低*）、最後一筆價格（*收盤價*），以及成交量（*volume*）。1 分鐘 K 棒就是一分鐘的摘要。

**K 棒週期（Interval）**
:   每根 K 棒涵蓋多長的時間：`1m`、`5m`、`15m`、`30m`、`1h` 或 `1d`（一個交易日）。

**即時報價（Snapshot）**
:   某檔股票最新的報價：最新成交價、當天到目前為止的開盤價、最高價和最低價，以及最佳買價和賣價。和 K 棒不同，它代表的是「現在」。

**技術指標（Indicator）**
:   從過去價格算出來的數字，例如移動平均線或布林通道。CJTrade 用 TA-Lib 計算。

**行情來源（Market data source）**
:   價格從哪裡來：Sinopac（需要帳戶）、FinMind 和 Yahoo Finance（免費），或是你電腦上的價格檔。

## CJTrade 用語

**ArenaX**
:   CJTrade 內建的模擬券商。它是一個小伺服器，用 `uv run arenaxd` 啟動。它有自己的現金和持股，會接收委託，並用過去的真實價格讓委託成交。它有四種模式，稱為*後端（backend）*：

    | 後端 | 價格 | 委託送到 | 用途 |
    |---|---|---|---|
    | `demo`（預設） | Yahoo Finance，最近幾週 | ArenaX | 隨便試試 |
    | `backtest` | Sinopac，或任何你選的來源 | ArenaX | 重播你選定的期間 |
    | `paper` | Sinopac，即時 | ArenaX | 在交易時段做紙上交易 |
    | `real` | Sinopac，即時 | **你的 Sinopac 正式帳戶** | 透過 ArenaX 做真實交易 |

**模擬時鐘（Simulated clock）**
:   ArenaX 不使用今天的日期。它會挑過去的某一天，從那天開始把市場往前播放，速度比真實時間快（`demo` 模式快 120 倍），並跳過晚上和週末。這裡說的「現在」是指 *ArenaX 的*現在。

**AccountClient**
:   你的程式和任何券商溝通時都用這一個 Python 物件：查詢餘額、下委託、取得價格。

**策略（Strategy）**
:   你的交易規則，寫成一個含有 `on_bar` 函式的 Python 檔。CJTrade 每根 K 棒呼叫它一次，它回答「買」、「賣」或「不動」。

**回測（Backtest）**
:   用過去的價格執行策略，看看它會有什麼結果。最快的一種是*一次性回測（oneshot）*，完全在記憶體中執行，幾秒內就跑完。

**交易引擎（Trading engine，`cjtrade`）**
:   用實盤的方式執行策略的程式：逐分鐘執行，每個策略在各自的行程（process）中運作，稱為一個 *bot（機器人）*。所有委託都會先經過同一個地方檢查，再送出去。

**Bot**
:   在交易引擎裡、針對某一檔股票執行的一個策略。

**風控閘門（Risk gate）**
:   交易引擎在每筆委託送到券商之前做的檢查：每個 bot 可以用多少錢、每根 K 棒最多幾筆委託，以及帳戶虧損太多時就停止。

**一買一賣（Round trip）**
:   一次買進，加上把它平倉的那次賣出。報表會以每一次一買一賣來計算輸贏。
