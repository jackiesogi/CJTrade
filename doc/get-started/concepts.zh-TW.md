# 基本概念

本文件通用的慣例與用語。

## CJTrade 的慣例

| 用語 | CJTrade 的慣例 |
|---|---|
| 股票代號（Symbol） | 只用交易所代碼：`2330`（台積電）、`0050`（元大台灣 50 ETF）。不寫成 `2330.TW`。 |
| 券商（Broker） | 任何能接收委託的對象：模擬券商 **ArenaX**，或正式券商 **Sinopac**、**Fubon**、**Yuanta**，各自由一個轉接層負責。 |
| 委託（Order） | 只是請求，下單不代表已成交。 |
| 成交（Fill） | 只有成交會改變現金和持股。 |
| 限價（Limit price） | 市價始終未到限價的委託會持續掛著。 |
| 整張與零股（Lot / odd lot） | 一張為 1,000 股。下單簡便函式預設交易零股，`quantity=1` 即一股，範例的成本因此較低。 |
| ROD、IOC、FOK | **ROD**（Rest of Day，當日有效）為預設值，掛到當天收盤。IOC 和 FOK 須立即成交，否則取消。 |
| 庫存（Position） | 單一股票的持有股數及平均成本。 |
| 餘額（Balance） | 現金，單位為新台幣。 |
| 交易時段（Trading session） | 證交所週一至週五 09:00 至 13:30，國定假日除外。 |
| 手續費與證交稅（Commission and tax） | 每筆成交收取成交金額 0.1425% 的手續費，最低 NT$20。賣出另收證交稅：股票 0.3%，ETF 0.1%（代號以 `0` 開頭）。每一筆模擬成交同樣計收。 |
| K 棒（Bar / K-bar） | 開、高、低、收、量。成交量以張為單位。日內 K 棒的時間戳記是該根 K 棒結束的那一分鐘；日 K 棒的時間戳記為 09:00。 |
| K 棒週期（Interval） | `1m`、`5m`、`15m`、`30m`、`1h` 或 `1d`（一個交易日）。 |
| 即時報價（Snapshot） | 最新報價：最新成交價、當日至今的開盤價、最高價、最低價，以及最佳買價和賣價。 |
| 技術指標（Indicator） | 以 TA-Lib 計算（移動平均線、布林通道等）。 |
| 行情來源（Market data source） | Sinopac（需要帳戶）、FinMind 和 Yahoo Finance（免費），或本機的價格檔。 |

## CJTrade 用語

**ArenaX**
:   CJTrade 內建的模擬券商，是以 `uv run arenaxd` 啟動的本機伺服器。它有自己的現金和持股，接收委託並以真實的歷史價格撮合成交。它有四種模式，稱為*後端（backend）*：

    | 後端 | 價格 | 委託送到 | 用途 |
    |---|---|---|---|
    | `demo`（預設） | Yahoo Finance，最近幾週 | ArenaX | 試用 |
    | `backtest` | Sinopac，或任何你選的來源 | ArenaX | 重播選定的期間 |
    | `paper` | Sinopac，即時 | ArenaX | 在交易時段做模擬交易 |
    | `real` | Sinopac，即時 | **你的 Sinopac 正式帳戶** | 透過 ArenaX 做真實交易 |

**模擬時鐘（Simulated clock）**
:   ArenaX 不以今天的日期執行。它從過去的某一天開始，以快於真實時間的速度推進市場（`demo` 模式為 120 倍），並跳過夜間和週末。文件中的「現在」一律指 ArenaX 的模擬時間。

**AccountClient**
:   與所有券商溝通的單一 Python 物件：餘額、委託、價格。

**策略（Strategy）**
:   含有 `on_bar` 函式的 Python 檔。CJTrade 每根 K 棒呼叫它一次，它回傳買、賣或不動。

**回測（Backtest）**
:   用歷史價格執行策略。最快的*一次性回測（oneshot）*完全在記憶體中執行，數秒內完成。

**交易引擎（Trading engine，`cjtrade`）**
:   以實盤的方式執行策略：逐分鐘執行，每個策略在各自的行程（process）中運作，稱為一個 *bot*；所有委託在送到券商前都先經過同一個檢查點。

**Bot**
:   在交易引擎裡、針對某一檔股票執行的一個策略。

**風控閘門（Risk gate）**
:   交易引擎在每筆委託送到券商前所做的檢查：每個 bot 的資金上限、每根 K 棒的委託數上限，以及帳戶虧損過大時停止交易。

**一買一賣（Round trip）**
:   一次買進加上將其平倉的賣出。報表以每一次一買一賣計算輸贏。
